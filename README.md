# career-ops-mounir

Repo PRIVADO. Busqueda automatica de ofertas + CV optimizado por oferta, basado en [career-ops](https://career-ops.org/).

- `cv.md` CV base (fuente de verdad, no inventar nada fuera de el)
- `config/profile.yml` filtros: salario, ingles, formacion, zona
- `config/portals.yml` webs a escanear (sin LinkedIn)
- `data/seen.csv` registro de empresas/ofertas ya vistas (no repetir)
- `reports/` informe por ejecucion (ofertas rankeadas)
- `cvs/` CVs optimizados por oferta
- `CLAUDE.md` instrucciones del agente cloud (rutina cada 3 horas)
